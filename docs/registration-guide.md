## 🚀 SECTION 3: Step-by-Step Filing Instructions

### Step 1: Incorporate ImeanTech Ltd on BRS eCitizen
1. Go to `ecitizen.go.ke` → Click **Business Registration Service (BRS)**.
2. Click **Make Application** → Select **Private Limited Company**.
3. Type name: `ImeanTech Limited`.
4. Paste **Physical Registered Office** and **Share Capital Structure** from Section 2.
5. Paste **Business Objects Clause** from Section 2.
6. Enter Director details (Lewis Ndungu) and assign 1,000 shares (100%).
7. System generates 4 statutory forms:
   - **CR1** (Company Application)
   - **CR2** (Memorandum & Model Articles)
   - **CR8** (Notice of Residential Address)
   - **Shareholder Consent**
8. Download forms, sign them, and upload scanned PDFs back to eCitizen.
9. Pay **KES 10,650** via M-Pesa.
10. Wait 1–3 business days → Download **Certificate of Incorporation** and **CR12**.

---

### Step 2: Post-Incorporation (Company KRA PIN & IP Assignment)
1. **Company KRA PIN (Free):**
   - Go to `itax.kra.go.ke` → **New PIN Registration** → **Non-Individual (Company)**.
   - Enter Certificate of Incorporation number and CR12 details → Receive Company KRA PIN instantly.
2. **Founder IP Assignment (Free):**
   - Sign the 1-paragraph IP agreement in [`legal-ip-ownership-memo.md`](file:///c:/Users/lewis/Desktop/wangari/docs/legal-ip-ownership-memo.md) assigning Wangari code, brand, and domains from founder to `ImeanTech Ltd`.

---

### Step 3: Register "Wangari" Trademark at KIPI
* **Proprietor Name:** `ImeanTech Limited`
* **Trademark Classes:** Class 9 (Software) & Class 42 (SaaS/Cloud Services)

| Stage | Action | Fee (KES) |
|---|---|---|
| **1. Preliminary Search (Form TM 27)** | Check if "Wangari" is free in Class 9/42 | **KES 2,000** |
| **2. Application (Form TM 2)** | File application naming ImeanTech Ltd as owner | **KES 5,000** |
| **3. Journal Publication** | Advertise in Industrial Property Journal | **KES 3,000** |
| **4. Certificate Issuance** | Collect Trademark Certificate (after 60-day window) | **KES 2,000** |
| **TOTAL KIPI COST** | | **~KES 12,000** |

---

### Step 4: Optional Business Name Filing ("Trading As")
1. On BRS eCitizen, select **Register Business Name**.
2. Enter name: `Wangari` (or `Wangari Farm OS`).
3. Set proprietor as **ImeanTech Limited**.
4. Pay **KES 950** → Receive certificate: *ImeanTech Limited trading as Wangari*.
